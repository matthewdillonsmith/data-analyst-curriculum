# Student Materials

The datasets increase in complexity as you progress through the program.

A central expectation is that you learn to validate data before trusting it.

By the advanced stages, assignments may intentionally provide only a business problem. You are expected to determine:

- Which sources are relevant
- What one row represents
- Which keys are reliable
- Whether records are missing or duplicated
- Which business definition should be used
- How the result should be validated
- Which tool is appropriate

Do not assume that a technically valid query produces a correct business answer.
