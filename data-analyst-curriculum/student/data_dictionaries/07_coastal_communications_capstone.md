# Stage 07 Data Dictionary — Coastal Communications Cooperative

This documentation is intentionally incomplete. Part of the capstone is determining business meaning through profiling, source comparison, and stakeholder-style requirements work.

| Table | General purpose |
|---|---|
| `members` | CRM member records |
| `addresses` | Member mailing addresses |
| `accounts` | Service/billing accounts |
| `plan_history` | Historical service-plan assignments |
| `bills` | Monthly billing transactions |
| `payments` | Payment transactions |
| `adjustments` | Billing adjustments |
| `service_orders` | Operational service orders |
| `service_order_events` | Service-order event history |
| `devices` | Installed network devices |
| `device_status_history` | Device status events |
| `outages` | Network outage events |
| `account_balance_snapshots` | Point-in-time account balances |

Several fields use abbreviated codes. Some definitions are not provided in advance. Students should identify which definitions require stakeholder clarification rather than guessing.
