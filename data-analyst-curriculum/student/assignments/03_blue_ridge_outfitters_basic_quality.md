# Stage 03 Assignment — Raw Data Quality

Management wants the same analysis produced from the raw Blue Ridge Outfitters extracts.

Before calculating business metrics:

1. Create a data-quality profile.
2. Define the intended grain and key for each table used.
3. Identify data issues that could materially affect revenue, customer, or geographic reporting.
4. Create reproducible cleaning/normalization logic.
5. Reconcile cleaned totals to source counts.
6. Produce a short data-quality report explaining what was changed, what was not changed, and why.
7. Re-run the Stage 02 management analysis from the cleaned data.

Do not assume every unusual value is an error.
