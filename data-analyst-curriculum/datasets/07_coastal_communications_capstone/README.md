# Coastal Communications Cooperative

**Stage:** `07_coastal_communications_capstone`  
**Difficulty:** Stage 7 — Advanced Enterprise Capstone

A fictional telecommunications cooperative used as the final academic simulation before the real electric-cooperative internship. Some documentation is intentionally incomplete on the student side.

## Included formats

- `csv/` — one CSV per table
- `json/` — one JSON array per table
- `database/07_coastal_communications_capstone.sqlite` — ready-to-query SQLite database
- `sql/postgresql_schema.sql` — PostgreSQL DDL
- `sql/sqlserver_schema.sql` — SQL Server DDL
