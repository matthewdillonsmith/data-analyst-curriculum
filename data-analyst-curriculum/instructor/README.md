# Instructor Materials

This directory contains information that reveals the intended ground truth of the synthetic datasets.

Do not provide `manifests/` or `answer_keys/` to students before grading is complete.

## Manifests

Each YAML file records:

- Stage and difficulty
- Row counts
- Teaching objective
- Known intentionally injected defects
- Ground-truth defect counts
- Instructor-only business definitions or code mappings when relevant

## Answer keys

Answer keys describe the expected analytical behaviors and key discoveries. They intentionally focus on validation and reasoning rather than requiring one exact SQL/Python implementation.
